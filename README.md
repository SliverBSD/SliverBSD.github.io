SliverBSD is a project to port a os to a lot of weird architectures

# what’s planned
SliverBSD has implemented support for the following below. (it will release open source soon)
- ppc/wii
- x86_64
# When will a package manager be released
currently, package managers are NOT “planned” until further notice

# will SliverBSD inherit all architectures from FreeBSD 
No, SliverBSD will not inherit any architecture support from FreeBSD. additionally we won’t use their package manager.
